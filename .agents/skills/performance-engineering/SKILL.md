# Performance Engineering

Prioritize:
- Excellent Core Web Vitals
- Fast initial rendering
- Minimal JavaScript
- Small bundles
- Astro static generation
- Efficient CSS
- Optimized images
- Minimal third-party scripts
- Mobile performance

Before adding a dependency, determine whether the functionality can be implemented cleanly without it.

Treat avoidable performance regressions as bugs.
