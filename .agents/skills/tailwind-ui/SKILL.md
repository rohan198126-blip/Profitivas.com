# Tailwind UI Engineering

Build a premium modern business-software interface.

Priorities:
- Mobile-first responsive design
- Excellent typography
- Strong spacing and hierarchy
- Clear forms and calculator inputs
- Highly readable results
- Consistent design tokens
- Reusable components
- Accessible states
- Minimal visual clutter

Avoid:
- Excessive gradients
- Excessive glassmorphism
- Generic AI landing-page aesthetics
- Huge hero sections
- Unnecessary animation
- Visual noise

The calculator and its results should remain the primary focus.
