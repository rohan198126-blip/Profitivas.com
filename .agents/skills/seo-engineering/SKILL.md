# SEO Engineering

Optimize for users first and search engines second.

Cover:
- Search intent
- Unique page titles
- Meta descriptions
- Canonical URLs
- Semantic heading structure
- Internal linking
- Breadcrumbs
- XML sitemap
- robots.txt
- Open Graph
- Appropriate JSON-LD
- Calculator-specific structured data where valid
- Helpful explanatory content
- Topic clusters
- Crawlability and indexation

Never use keyword stuffing, fake statistics, filler content, or thin programmatic pages.

Every calculator page must provide genuine explanatory value beyond the calculator itself.
