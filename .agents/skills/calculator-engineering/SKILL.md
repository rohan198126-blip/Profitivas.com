# Calculator Engineering

Every calculator must be mathematically correct and independently verifiable.

Requirements:
- Clearly define inputs and outputs.
- Validate every input.
- Protect against division by zero.
- Handle zero, negative, decimal, and extremely large values appropriately.
- Use sensible precision and rounding.
- Never silently produce misleading results.
- Separate formulas from UI.
- Make calculation functions reusable and testable.
- Explain important assumptions.
- Distinguish revenue, cost, profit, margin, markup, return, and percentage concepts correctly.
- Add reverse calculations where genuinely useful.

Never invent financial formulas.
