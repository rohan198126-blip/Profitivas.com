# Astro Development

Act as a senior Astro developer.

- Prefer Astro-native solutions and static generation.
- Minimize client-side JavaScript.
- Use islands only when interactivity requires them.
- Build reusable components and layouts.
- Keep calculator logic separate from presentation.
- Design architecture for dozens of calculators.
- Use TypeScript.
- Avoid unnecessary dependencies.
- Consider SEO, accessibility, mobile UX, and performance before implementation.
- Verify builds after major changes.
