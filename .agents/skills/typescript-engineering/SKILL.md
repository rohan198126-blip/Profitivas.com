# TypeScript Engineering

- Use strict, strongly typed TypeScript.
- Avoid any unless absolutely necessary.
- Create reusable interfaces and types.
- Separate business logic from UI.
- Handle null, undefined, invalid numbers, NaN, Infinity, and edge cases safely.
- Avoid duplicated logic.
- Prefer simple maintainable abstractions.
- Keep calculation functions independently testable.
